# 投研分析框架 — 七大模块详细问题清单

本文件在 Phase 3 加载，提供每个分析模块的具体研究问题。回答每个问题时，必须附上证据来源。

---

## 模块 1：关键问题分析

### 1.1 这家公司靠什么赚钱？

核心问题：
- 客户是谁？为什么客户会持续付费？
- 收入结构（产品线 / 地区 / 客户类型 / 商业模式：订阅 / 交易 / 广告 / 硬件+服务），近 3-5 年变化与驱动因素
- 单位经济模型（unit economics）：定价 × 毛利 × 获客成本 × 留存/复购 × 扩张
- 识别最核心的增长方程式——增长主要靠什么变量驱动？

分析要点：
- 将收入拆解为最细粒度，找到贡献最大增量的业务线
- 绘制单位经济模型的关键指标链，识别瓶颈环节
- 判断增长是"花钱买来的"还是"自然发生的"

### 1.2 有什么别人学不会的？（供给的独占性）

逐项判断，每一项都需要定量证据：

| 护城河类型 | 关键判断问题 | 定量指标示例 |
|---|---|---|
| 转换成本 | 客户离开的代价有多大？ | 流失率、迁移成本估算 |
| 网络效应 | 用户增加是否让产品更好？ | N>N₀ 的临界点、双边平台密度 |
| 规模经济 | 规模扩大是否降低单位成本？ | 边际成本曲线、单位固定成本下降 |
| 品牌 | 品牌是否带来溢价或降低获客成本？ | 品牌溢价率、自然流量占比 |
| 数据 | 数据积累是否形成壁垒？ | 数据量级、数据飞轮效应 |
| 生态 | 生态参与者是否互相增强？ | 开发者数量、插件/应用数 |
| 监管 | 牌照/合规是否限制新进入者？ | 牌照获取难度、合规成本 |
| 技术领先 | 技术差距是否可持续？ | 专利数、研发投入 vs 竞品 |

关键追问：
- 护城河从哪里来？如何被量化验证？是否在变强或变弱？
- 对上下游有议价权吗？过去是否多次提价？提价后流失如何？
- 竞争对手能不能用不同路径绕过你？
- **"Moat 的半衰期"**：如果未来 5 年技术变了，护城河还在吗？
- 主要对手列表：明确差异化维度、价格/渠道/产品路线、指出最可能的"竞争拐点"
- 这个市场最终会不会变成低毛利的？如果是，如何保持绝对的净利润值？

### 1.3 需求的稳定性

- 客户付费意愿 + 付费频率 + 刚需程度 + 预算来源
- 需求是否随经济周期大幅波动？
- 预算来自"必须花"还是"可以省"的科目？

### 1.4 增长引擎

- 增长靠直销 / 渠道 / 投放？
- 渠道是否会反噬（佣金上涨、议价能力增强）？
- 增长速度与单位经济健康度是否矛盾？

### 1.5 市场还有多少空间？

- TAM / SAM / SOM 分别估算 + 增长驱动 + 渗透率逻辑
- **对"市场规模/份额"这类最易编造的数字**：至少两家独立来源交叉验证
- 明确"空间到底来自哪里"：
  - 替代旧方案？
  - 新增需求的渗透率提升？
  - 价格提升？
  - 品类扩张？

### 1.6 还有哪些利润池没有释放？

- 利润池在哪里：价值链哪一段拿走利润？（上游 / 中游 / 下游）
- 公司现在拿的是哪一段？未来能否"上移/下沉"吃到更多？
- 是否存在"交叉补贴"或"先亏后赚"的必经阶段？

## 模块 2：企业文化与组织管理

用**可观测证据**（而非口号）描述：

### 2.1 文化是否适配商业模式？

- 招聘画像：招什么样的人？看重什么特质？
- 研发投入节奏：是持续高投入还是周期性？与行业特征匹配吗？
- 组织架构：集中决策 vs 分权？是否匹配业务复杂度？
- 决策机制：数据驱动还是直觉驱动？决策速度如何？
- 对失败的态度：是否有容错机制？失败后如何调整？
- 内部流程：是赋能型还是管控型？

### 2.2 组织效率

- 人均产出（收入/利润 per employee）趋势
- 关键岗位人才流失率
- 跨部门协作效率的可观测指标

### 2.3 文化如何影响战略

- 它如何让战略更容易执行？
- 它如何让坏事更难发生？
- 文化和组织形式在规模化后会不会不可持续？

### 2.4 激励机制

- 奖金看收入还是自由现金流？
- 会不会逼出"坏增长"（牺牲利润率换收入、激进会计）？
- SBC（股权激励）是否过度？占收入和自由现金流的比例趋势

## 模块 3：财务与用户数据

### 3.1 收入质量

- 一次性收入 vs 经常性收入占比及趋势
- 递延收入变化（暗示未来收入可见性）
- 续费率 / 净收入留存率（NRR）
- 客户集中度（Top 10 客户占比）
- 合同期限分布

### 3.2 毛利与费用结构

- 毛利率水平与趋势，与竞品对比
- 研发 / 销售 / 管理费用率及趋势
- 规模效应是否显现（收入增速 > 费用增速）
- 哪个费用项最可能被优化？哪个最可能恶化？

### 3.3 净利润 vs 自由现金流

- 近 3-5 年净利润和自由现金流数据
- 偏差在哪里？原因是什么？（递延收入 / 应收 / 存货 / 资本化）
- 自由现金流转化率（FCF / 净利润）趋势

### 3.4 ROE / ROIC

- ROE 和 ROIC 大概多少？
- ROIC 的来源是真竞争力还是杠杆/会计 tricks？
- 杜邦分析拆解：利润率 × 周转率 × 杠杆

### 3.5 资本配置

- 赚到的现金流去哪了：回购注销 / 分红 / 并购 / 投资？
- 管理层过往承诺兑现率
- 并购是补短板还是遮盖自身增长不足？并购后整合效果如何？
- 回购是否在"对的价格"做？（对比回购均价与当时估值）

### 3.6 股权稀释（SBC）

- SBC 占收入比例趋势
- SBC 占自由现金流比例
- 完全稀释股数 vs 基本股数的差异趋势
- SBC 是否侵蚀了股东真实回报？

### 3.7 财务与会计质量

- 收入确认是否复杂？是否存在提前确认的嫌疑？
- 一次性收入占比是否过高？
- 现金流 vs 利润的背离原因（递延收入、应收、存货）
- 是否存在频繁的会计政策变更？
- 审计师意见是否有保留？

## 模块 4：市场共识与冷门事实

### 4.1 关键不确定性清单

- 列出当前结论依赖的关键假设
- 明确哪些结论是"高置信度"，哪些是"假设驱动"

### 4.2 过往挑战与错误

- 过去公司遇到了哪些竞争、监管等挑战？
- 犯过哪些错误？如何应对的？具体事实是什么？
- 从应对方式中能看到管理层的什么特质？

### 4.3 五个最致命的风险

如果 5 年后这家公司的净利润腰斩，最可能的原因是什么？

每条风险需要覆盖以下维度中的至少一个：技术替代、竞争、监管、供应链、客户预算、地缘政治、财务风险、关键人、渠道依赖

每条风险必须给出**触发信号**（什么可观测指标出现时，说明风险正在变为现实）

### 4.4 叙事风险

- 市场预期是否过高，导致小失误大回撤？
- 哪些"共识"最容易被打破？
- 当前估值隐含的增长预期是否合理？

## 模块 5：理解创始人

### 5.1 价值观一致性

- 创始人过去在面临巨大诱惑或危机时，做出了什么选择？
- 这些选择是否符合他宣称的价值观？
- 关键决策时刻：融资、并购、裁员、产品转型、面对做空

### 5.2 "说到做到"记录

- 管理层设定的目标是否反复改口？
- 历年指引 vs 实际达成情况的对比
- 对miss的归因是否合理？

### 5.3 思维方式

- 创始人怎么思考问题？
- 公开推荐的书单、演讲、访谈中体现的思维模型
- 是第一性原理思考者还是经验驱动？

### 5.4 推荐研究材料

**书籍**（输出电子书名字，供逐段引用 + 标注页码/段落 + 分离事实/观点/推断）：
- 关于该公司的权威书籍
- 创始人/CEO 著作
- 行业经典著作

**公司一手资料**：
- 年报 / 10-K / 20-F
- 投资者日材料
- 电话会纪要
- 官方博客 / 技术白皮书

**行业权威**：
- 大型咨询 / 券商 / 行业协会 / 监管机构 / 学术综述

**高质量媒体深度**（少量精选）：
- 长篇深度报道
- 纪录片
- 播客访谈

## 模块 6：多元视角审视

用五个不同视角重新审视这家公司，每个视角关注不同维度：

### 6.1 巴菲特视角

关注：竞争格局与护城河、可预测性、是否在回答过于难的题目、管理层诚信与资本配置能力
核心问题：这是一个"不需要聪明人也能经营的好生意"吗？

### 6.2 马斯克视角

关注：巨大的技术变革会如何影响、可规模化性、对世界的改变和价值、是否会被其他公司和技术折叠
核心问题：5-10 年后这家公司会不会被技术进步"降维打击"？

### 6.3 迈克尔·波特视角

关注：五力模型分析（供应商议价力、买方议价力、新进入者威胁、替代品威胁、行业竞争强度）、价值链定位、战略取舍
核心问题：这家公司的战略取舍是否清晰且可持续？

### 6.4 吉姆·柯林斯视角

关注：第五级领导力、刺猬理念（你最擅长什么/什么驱动你的经济引擎/你热爱什么）、纪律文化、从优秀到卓越的飞轮
核心问题：这家公司是否有一个清晰的飞轮在自我强化？

### 6.5 普通用户/朋友视角

关注：产品是否真正解决痛点、信任感、口碑、是否愿意长期使用和推荐
核心问题：如果你朋友是这家公司的客户，他们会怎么说？
