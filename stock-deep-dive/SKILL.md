# Stock Deep Dive（价值投资漏斗分析）

对一只股票执行完整的漏斗式深度分析——从快速排除到全面确认，六层递进，每层设有 Go/No-Go 检查点，不通过即终止，避免在劣质标的上浪费精力。

## 核心理念

本技能整合了四位价值投资大师的思想体系，形成递进式"排除→确认→证伪→校准→定位→汇总"的工作流：

- **老唐**：财报排雷与三大前提，第一道硬门槛——"财报是用来排除企业的"
- **巴菲特**：护城河与商业模式，判断"这是不是一门好生意"
- **芒格**：反向思考与误判排查，寻找"我可能错在哪里"
- **段永平**：本分校验与理解深度，追问"我真的看懂了吗"
- **波特**：竞争定位与行业结构，补充"竞争优势从何而来"

**分析不是投票**——不是各框架打分取平均，而是：先用老唐/Buffett 正向确认"好不好"，再用 Munger/段永平反向找"哪里可能错"，最终决策权在用户自己。

## 你的工作方式

采用条件流程——每一层都有明确的 Go/No-Go 检查点：

```
Layer 1: 三大前提+财报排雷（老唐框架）
  ├── 🔴 No-Go → 终止，输出排除理由
  └── 🟢 Go ↓
Layer 2: 护城河+商业模式（巴菲特框架）
  ├── 🔴 No-Go → 终止，输出排除理由
  └── 🟢 Go ↓
Layer 3: 反向思考+误判排查（芒格框架）
  ├── 🔴 No-Go（致命风险） → 终止，输出风险分析
  ├── 🟡 Conditional-Go（重大风险） → 降级观察，定义监控指标
  └── 🟢 Go ↓
Layer 4: 本分校验+理解深度（段永平框架）
  ├── 🔴 No-Go → 终止，标注"不在能力圈"
  └── 🟢 Go ↓
Layer 5: 竞争定位+行业结构（波特框架，可选）
  └── 🟢 补充竞争分析 ↓
Layer 6: 汇总输出投资备忘录
```

用户可指定分析深度：
- **快速筛选**：仅执行 Layer 1-2，判断是否值得深入研究
- **标准分析**：执行 Layer 1-4，覆盖核心漏斗
- **全面分析**（默认）：执行 Layer 1-6，含竞争定位与完整备忘录

> 🔴 **CHECKPOINT**：全面分析默认执行 Layer 1-6，若关键数据缺失（无法获取年报/公告）导致分析无法推进，向用户确认后再继续或降级分析深度。

## Layer 1：三大前提检验 + 财报排雷

> 来源：老唐投资体系。知识库 ID：`35oQB8HxJYo-CZRPQ9S6OkZhXu97zEkfN629ulSUEXs=`

**目标**：用最快速度排除不合格的企业。财报是用来排除企业的，不是用来挑选企业的。

### 1.1 三大前提检验

逐条检验，三条中有任何一条不满足即 No-Go：

1. **利润为真**：经营现金流净额是否长期大于净利润？是否存在大量应收/关联交易/非经常性损益？审计意见是否无保留？
2. **利润可持续**：行业是否衰退？竞争格局是否恶化？核心产品是否面临替代？政策是否可能颠覆商业模式？
3. **维持盈利无需大量资本投入**：资本开支/净利润比值？是否重资产行业？折旧摊销能否覆盖维持性支出？

### 1.2 财报排雷

对通过三大前提的企业，快速扫描三张表核心科目：

- **资产负债表**：货币资金异常（存贷双高）、应收账款增速远超营收、存货异常增长、在建工程长期不转固、商誉大幅增加
- **利润表**：非经常性损益占比高、毛利率异常提升、减值损失随意计提或转回
- **现金流量表**：经营现金流长期远低于净利润

> 详细的排雷检查清单，读取 `references/financial-checklist.md`

### 1.3 数据缺失容错

- **年报数据找不到**：先标注"数据待查证"，继续用已有公告/行业数据完成初步判断；若核心数据（现金流、利润）完全无法获取 → 终止，提示用户提供数据源
- **审计意见无法确认**：视为"需关注"黄灯，不因此单独否决，但在输出中明确标注
- **行业数据缺失（利润可持续判断）**：说明判断依据的局限性，基于可获取信息做保守假设

### Go/No-Go 判定

> 🔴 **No-Go**：三大前提任一条不满足，或财报发现重大异常无法合理解释 → **终止分析**，输出排除理由，不再进入 Layer 2

> 🟢 **Go**：三大前提全过 + 无重大财报异常 → 进入 Layer 2

## Layer 2：护城河 + 商业模式检验

> 来源：巴菲特投资体系

**目标**：判断这家企业是否拥有可持续的竞争优势，是否是一门好生意。

### 2.1 商业模式分类

将企业归入三类：

| 类型 | 特征 | 态度 |
|------|------|------|
| 市场特许型 | 产品被需要、不可替代、定价自由 | 优选 |
| 一般竞争型 | 大众化同质化产品，利润薄 | 回避 |
| 两者之间型 | 强势一般竞争型或弱势特许型 | 需评估 |

### 2.2 护城河检验

按五项标准逐条检验：

1. **多样化**：护城河来源是否多元（品牌/成本/网络/监管/转换成本）？
2. **清晰可辨**：能否一句话说清护城河？说不清则大概率不存在
3. **可以持久**：10-20年后护城河是否还在？
4. **难以逾越**：有足够资金和人才，对手是否愿意挑战？
5. **不依赖个人**：离开关键人物，护城河是否仍在？

### 2.3 管理层评估

- 管理层是否坦诚（尤其是坏消息）？
- 资本配置能力如何（回购/分红/并购历史）？
- 管理层是否"爱自己管理的公司甚于爱股东的钱包"？

### 2.4 数据缺失容错

- **护城河无法判断（信息不足）**：不应给出"有护城河"结论——按"说不清则大概率不存在"原则，降级为观察；在输出中标注"护城河存疑，需进一步查证"
- **管理层信息不足**：标注"管理层评估待补充"，不影响 Go/No-Go，但应在下一步验证行动中列入

### Go/No-Go 判定

> 🔴 **No-Go**：无清晰护城河，或属一般竞争型且无特殊优势 → **终止**，输出排除理由

> 🟢 **Go**：有可识别的护城河 + 商业模式至少"两者之间型" → 进入 Layer 3

## Layer 3：反向思考 + 误判排查

> 来源：芒格思想体系

**目标**：系统性地寻找"我可能错在哪里"，而非寻找更多支持买入的理由。

### 3.1 失败路径分析

罗列一切可能导致投资失败的因素：

- **商业模式失效**：护城河被消解的路径有哪些？技术颠覆？监管变化？消费者偏好迁移？
- **管理层风险**：激励扭曲？诚信问题？过度扩张？
- **行业结构性变化**：五力格局恶化？利润池被侵蚀？
- **估值风险**：当前价格是否已充分反映乐观预期？

### 3.2 误判心理学排查

检查分析过程中可能受哪些认知偏差影响：

1. 是否因已有持仓/先入为主而倾向看多？（激励偏差）
2. 是否因市场共识看多而不敢独立判断？（从众效应）
3. 是否因已投入研究时间而不愿放弃？（沉没成本/被剥夺超级反应）
4. 是否因品牌知名度而忽视风险？（简单联想）
5. 是否存在多种偏差叠加的 Lollapalooza 效应？

### 3.3 逆向检验

**步骤**：对每个看好的理由，执行以下逆向检验——
1. 列出该理由的最强反驳论点
2. 判断反驳是否能被有效回应
3. 若无法回应 → 该理由不成立，标记为风险

### 3.4 Conditional-Go 监控指标定义（重大风险降级流程）

当判定为"重大但可监控风险"时，**必须**执行以下三步，不可跳过：

1. **命名风险**：用一句话精确描述这个风险（例："抖音效果广告将分流楼宇广告预算"）
2. **定义监控指标**：给出 2-3 个可量化的先行指标（例：分众单屏收入同比、广告主结构中中小企业占比）
3. **设定触发条件**：明确"若X发生则重新评估是否终止"（例："若连续两季度单屏收入同比下滑超 15%，则触发重新评估"）

### 3.5 数据缺失容错

- **失败路径分析无法覆盖某领域（如行业数据不足）**：说明该路径"暂无法评估"，在待验证问题中列入，不因此跳过该路径的槽位
- **无法完成所有偏差排查**：至少完成前3条（激励/从众/沉没成本），其余标注"待自查"

### Go/No-Go 判定

> 🔴 **No-Go（致命风险）**：存在无法反驳的致命风险（如治理结构根本性缺陷、行业面临不可逆衰退）→ **终止**，输出风险分析

> 🟡 **Conditional-Go（重大风险）**：存在重大但可监控的风险 → **降级为"观察"**，必须完成 3.4 节监控指标定义，再进入 Layer 4

> 🟢 **Go**：风险可控，失败路径均可被有效反驳 → 进入 Layer 4

## Layer 4：本分校验 + 理解深度

> 来源：段永平思想体系

**目标**：追问"我真的看懂了吗"，而非"这个分析看起来没问题"。

> 🔴 **CHECKPOINT**：本层需要用户的能力圈信息参与判断。若用户未主动提供相关背景，先自行基于公开信息评估"这门生意是否能被普通投资者看懂"，再在输出中提示用户自查不为清单。

### 4.1 不为清单检验

逐条排查是否触碰"不为"红线：

- 是否在看不懂的生意？→ 不懂不碰
- 是否因为"别人也在买"或"概念很热"？→ 这不是理由
- 是否在试图"抄作业"而不理解背后逻辑？
- 是否在做空或打算用杠杆？→ 不做空、不用 margin

### 4.2 理解深度评估

段永平的安全边际 ≠ 价格折扣，而是**对公司的理解深度**：

- 能否用一段话说清楚这家公司靠什么赚钱？
- 10年后这家公司大概率会比现在赚更多还是更少？
- 如果股市关闭5年，是否愿意持有？
- 假设公司不上市，是否愿意用当前市值买下整个公司？

### 4.3 长期视角检验

- 商业模式是否有"长坡厚雪"？
- 企业文化是否有"利润之上的追求"？
- 卖出条件是否清晰（仅两个：公司本质变了 / 有更好的机会）？

### 4.4 数据缺失容错

- **理解深度自评无法通过（信息不足）**：不应勉强给出"理解充分"结论——按保守原则标注"信息不足以评估，建议用户阅读[X]材料后再判断"
- **用户未提供能力圈信息**：基于"这门生意是否简单易懂"做客观评估，不代替用户做能力圈判断

### Go/No-Go 判定

> 🔴 **No-Go**：无法清晰说明公司靠什么赚钱，或判断为"不懂"→ **终止**，标注"超出能力圈"

> 🟢 **Go**：理解充分，能清晰描述商业模式和长期前景 → 进入 Layer 5（全面分析）或 Layer 6（标准分析）

## Layer 5：竞争定位 + 行业结构（可选）

> 来源：波特理论体系

**目标**：补充竞争视角，理解企业在行业中的战略定位。

**适用范围**：全面分析模式；快速筛选/标准分析可跳过。

### 5.1 五力模型速扫

对五种力量评定**强/中/弱**，每项必须填写关键判断依据（不可留空）：

| 力量 | 强/中/弱 | 关键判断依据 |
|------|---------|-------------|
| 新进入者威胁 | | 规模经济/品牌溢价/监管壁垒/技术壁垒？进入成本估算？ |
| 现有竞争者抗衡 | | 行业集中度/价格战历史/差异化程度？ |
| 替代品威胁 | | 替代品是否功能接近？切换成本？价格差？ |
| 买方议价能力 | | 买方集中度？标准化程度？转换成本？ |
| 供应商议价能力 | | 供应商集中度？原材料独特性？前向整合风险？ |

**合力判断**：五力整体对企业是否有利？行业整体利润率走势？

**判断标准**：
- 3力以上为"弱"（对企业有利）→ 行业结构优质
- 3力以上为"强"（对企业不利）→ 行业结构压力大，需与护城河对照评估
- 混合结果 → 说明主导力量是哪一项

### 5.2 战略定位诊断

- 企业属于成本领先/差异化/目标集中中的哪一种？
- 是否"夹在中间"（既想成本领先又想差异化却两者都不够）？
- 核心取舍是什么？该做但没做的取舍是否在削弱战略？

### 本层输出

不设 No-Go（本层为补充分析），但需识别：
- 竞争格局是否有利
- 战略定位是否清晰
- 行业利润池走向

## Layer 6：汇总输出投资备忘录

整合所有层级分析结果，生成一份完整的投资备忘录。

> 完整的输出模板，读取 `references/output-template.md`

### 老唐估值法执行步骤

在备忘录的"估值与行动条件"章节，按以下步骤计算：

1. **取基期自由现金流**：以最近3-5年经营自由现金流（FCF = 经营现金流 - 资本开支）的均值或中位数作为基期值，剔除明显一次性异常年份
2. **设保守增长率假设**：基于业务判断给出未来3年增长率，必须说明假设依据（例："基于近5年10%均值，保守取7%"）
3. **计算三年后 FCF**：基期 × (1+增长率)³
4. **套用估值公式**：合理估值 = 三年后 FCF / 无风险收益率（通常取 3%-4%）
5. **理想买点**：合理估值 × 50%
6. **一年内卖点**：取"合理估值 × 150%"与"当年 FCF × 50 倍"中的较低值
7. **当前安全边际**：(合理估值 - 当前股价) / 合理估值

> 若 FCF 数据无法获取，可使用净利润代替，但必须在备忘录中标注"使用净利润替代，存在高估风险"

## 反幻觉与证据规则

全流程遵守：

1. 事实性结论必须给出来源（年报/公告/权威媒体/知识库）
2. 无法确认就标注"未证实/需要查证"，绝不编造数字
3. 数据口径必须说明（TTM/年度/季度、合并/母公司）
4. 每份输出必须包含"我可能错在哪里"和"下一步验证行动"

**违反上述规则时**：强制停止生成当前段落，重新标注为"未证实"后继续——不允许以"大概"/"可能是"等软化措辞掩盖无来源的数字。

## ⛔ 不要做什么（反模式与黑名单）

### 分析行为禁止项

1. **不要美化 No-Go**：不要因为用户明显喜欢某只股票就软化排除结论，No-Go 就是 No-Go，必须直接说明
2. **不要跳过失败路径**：Layer 3 的失败路径分析不能因为"看好这只股票"而简化或走过场，每条路径必须认真对待
3. **不要用"可能""大概"替代来源**：无法确认的数字必须标注"未证实"，不允许用模糊措辞过关
4. **不要在能力圈之外强行给结论**：若判断为"不懂"，不要给出"综合来看可以关注"这类模糊正面结论——直接输出 No-Go

### Conditional-Go 处理禁止项

5. **不要跳过监控指标定义**：Conditional-Go 不等于降级版 Go——必须完整执行 3.4 节三步流程（命名风险 → 定义指标 → 设定触发条件），缺少任一步骤则重新执行
6. **不要将 Conditional-Go 当 Go 用**：降级观察的标的不应出现"综合判断值得买入"类结论，只能是"在X条件满足前保持观察"

### 估值禁止项

7. **不要脱离 FCF 基础做估值**：老唐估值法的基础是自由现金流，不允许直接用市值/市净率/PE 替代，若确实无 FCF 数据必须说明并标注风险
8. **不要给出"精确"的安全边际**：安全边际是粗略估算，不要输出"当前安全边际为 23.7%"这类虚假精确数字，应说明估算范围和假设局限

### 幻觉禁止项

9. **不要编造财报数据**：若无法通过搜索获取真实财报数据，必须中止并要求用户提供，不允许"合理估算"数字
10. **不要以示例中的茅台/分众数据类比**：示例是说明工作流的，不是提供真实数据的——不可将示例数字代入实际分析

## 工作流示例

### 示例 1：全面分析（默认模式）

用户："深度分析茅台"

1. Layer 1：搜索茅台近3年财报 → 三大前提检验（利润为真✅ 利润可持续✅ 无需大量资本✅）→ 财报排雷（无重大异常）→ 🟢 **Go**
2. Layer 2：商业模式分类（市场特许型）→ 护城河检验（品牌溢价+定价权，多元持久清晰）→ 管理层评估 → 🟢 **Go**
3. Layer 3：失败路径（消费降级、人口结构变化、政策风险）→ 误判排查（是否因"大家都知道茅台好"而从众？）→ 风险可控 → 🟢 **Go**
4. Layer 4：不为清单（茅台是否看得懂？✅）→ 理解深度（10年后大概率赚更多）→ 长期视角（长坡厚雪）→ 🟢 **Go**
5. Layer 5：五力模型速扫 → 战略定位诊断（差异化领先）→ 竞争格局有利
6. Layer 6：汇总输出投资备忘录，按 Layer 6 老唐估值法步骤计算合理估值，生成买入/卖出条件

### 示例 2：快速筛选（被排除的案例）

用户："快速看一下XX光伏公司值不值得研究"

1. Layer 1：三大前提检验 → 利润可持续❌（行业产能过剩、价格战、技术路线不确定）→ 🔴 **No-Go**
2. 终止分析，输出："不符合三大前提——利润可持续性存疑，建议排除。排除理由：[具体分析]"

### 示例 3：Conditional-Go 完整流程（重大风险降级观察）

用户："深度分析分众传媒"

1. Layer 1-2：通过
2. Layer 3：发现"抖音效果广告替代楼宇广告预算"为重大风险 → 🟡 **Conditional-Go**
3. **执行 3.4 节三步**：
   - ①命名："抖音效果广告分流，楼宇广告预算承压"
   - ②监控指标：分众单屏年收入同比、广告主续签率、中小广告主占比
   - ③触发条件：若连续两季度单屏收入同比下滑超15%，触发重新评估是否降为 No-Go
4. 标注"降级观察"，带风险条件继续 Layer 4
