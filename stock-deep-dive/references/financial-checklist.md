# 财报排雷检查清单

本清单用于 Layer 1 的财报排雷环节。按科目逐项检查，发现任一重大异常无法合理解释，即判定 No-Go。

> 来源：老唐《手把手教你读财报》体系，优先查看合并报表数据。

---

## 一、资产负债表排雷

### 1.1 货币资金

| 异常信号 | 含义 | 检查方法 |
|---------|------|---------|
| 余额远小于短期负债 | 短期偿债危机 | 对比短期借款+一年内到期非流动负债 |
| 充裕却借大量高息负债 | 资金可能虚构/被占用 | 对比有息负债利率与正常水平 |
| 定期存款多但流动资金缺乏 | 资金真实性存疑 | 查附注货币资金明细 |
| 其他货币资金巨大且无解释 | 异常 | 查附注受限资金说明 |

**交叉验证**：利息收入 ÷ 货币资金均值 = 实际利率，显著低于正常利率需警惕。

### 1.2 应收账款

| 异常信号 | 含义 |
|---------|------|
| 增幅远超收入增幅 | 放宽信用政策/提前确认收入 |
| 回款速度低于行业平均 | 竞争力下降或收入虚增 |
| 1年以上应收款占比超30% | 回收风险高 |
| 竞争激烈却几乎无应收 | 收入造假可能 |
| 大额收回同时新增其他应收/预付 | 资金腾挪操纵 |
| 突然改变坏账计提政策 | "洗大澡"或美化利润 |

**交叉验证**：查附注账龄分析、坏账计提比例、前五名欠款方，与同行业计提标准对比。

### 1.3 存货

| 异常信号 | 含义 |
|---------|------|
| 增幅远超营业成本增幅 | 可能通过采购流出资金 |
| 毛利率异常提升伴随存货大增 | 扩大生产摊薄成本虚增利润 |
| 应计提跌价却不计提 | 虚增利润（尤其电子/生鲜） |
| 生物资产价值难核实 | 造假高发区（农林渔牧） |

### 1.4 生产相关资产

| 异常信号 | 含义 |
|---------|------|
| 在建工程巨大迟迟不转固 | 避免折旧或资金挪用 |
| 突然改变折旧/摊销政策 | 调节利润 |
| 长期待摊费用金额大 | 费用资本化操纵 |
| 商誉突然大幅增加 | 收购作价存疑 |
| 固定资产大额减值 | 可能前期造假后"毁尸灭迹" |

### 1.5 投资相关资产

| 异常信号 | 含义 |
|---------|------|
| 持有至到期投资大额减值且随意转回 | 调节利润 |
| 金融资产分类随意变更 | 操纵利润表 |

## 二、利润表排雷

| 异常信号 | 含义 |
|---------|------|
| 利润依赖非经常性损益 | 经营稳定性差 |
| 毛利率异常提升但非竞争力/成本下降 | 可能虚增毛利率 |
| 减值损失随意计提或转回 | 利用减值操纵利润 |
| 生物资产余额大、减值随意 | 造假高发区 |

**高危行业**：农林渔牧 + 软件 + 集成电路 + 生物科技

**交叉验证**：成本/税收/费用占收入比与同行、历史对比，比例异常去附注找解释。

---

## 三、现金流量表排雷

| 异常信号 | 含义 |
|---------|------|
| 经营现金流长期远低于净利润 | 利润质量差 |
| 经营现金流为负（银行除外） | 经营不善 |
| 投资项目不在能力圈/回报率低于平均 | 资本配置能力差 |

**交叉验证**：现金流量表现金余额与资产负债表货币资金余额差异 = 受限资金，需在附注找到对应解释。

---

## 四、附注必查科目

- 货币资金明细：受限 vs 不受限
- 应收账款：账龄、坏账计提比例、欠款方构成
- 存货：构成、计价方式、跌价准备
- 固定资产/无形资产：折旧/摊销方法及变更
- 在建工程：明细、进度
- 商誉：减值测试参数
- 递延所得税：构成明细
- 研发支出：资本化/费用化标准
- 租赁相关：使用权资产和租赁负债

---

## 五、管理层披露交叉验证

- 历年经营计划兑现情况 → 管理层掌控力
- 行业竞争格局描述与同行对比 → 管理层判断力
- 员工人数与平均薪酬变化 → 与同行往年对比
- 前十大股东变化 → 聪明资金信号
- 关联交易与重要事项 → 风险排查
- 会计政策变更理由 → 是否调节利润

---

## 六、三表交叉验证关键逻辑

1. 净利润 + 未分配利润变化 ↔ 归母净资产变化
2. 经营现金流净额 ↔ 净利润（长期偏离 = 利润质量差）
3. 货币资金 ↔ 现金流量表现金余额（差异 = 受限资金）
4. 营收 ↔ 应收+预收变化 + 销售商品收到的现金
5. 管理层产能/销量表述 ↔ 固定资产/在建工程 + 营收 + 附注产销量

---

## 判定规则

如果财报分析发现**任一重大异常无法合理解释**，直接给出"财报存在重大疑点，建议排除"的结论。常见的"重大异常"包括：

1. 货币资金充裕却大量借高息负债
2. 应收增幅远超营收且坏账计提宽松
3. 在建工程长期不转固
4. 存货增速远超销售增速且行业非囤货增值型
5. 频繁变更会计政策/估计
6. 关联交易占收入比例高
7. 其他应收款金额大
8. 长期待摊费用异常偏高
