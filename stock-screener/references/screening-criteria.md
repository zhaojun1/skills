# 筛选条件库

本文件提供不同投资偏好下的完整筛选条件集，用于 Phase 2 量化条件生成。

所有条件均来源于价值投资大师框架的量化提取，是定性原则的量化代理——条件通过不代表公司一定好，但条件不通过通常意味着需要谨慎。

---

## 一、标准条件集（长期复利偏好）

适用于：大多数普通价值投资者，寻找可以长期持有的优质企业。

### 1.1 硬门槛（不满足即排除）

来源：老唐三大前提

| 指标 | 阈值 | 计算方法 | 对应的定性原则 |
|------|------|---------|-------------|
| 经营现金流/净利润 | ≥ 80% | 近3年经营现金流净额均值 ÷ 近3年净利润均值 | 利润为真 |
| ROE | ≥ 15% | 近3年归属母公司净利润均值 ÷ 近3年归属母公司净资产均值 | 利润可持续+资本效率高 |
| 资本支出/净利润 | ≤ 50% | 近3年购建固定资产等支付现金均值 ÷ 近3年净利润均值 | 维持盈利无需大量资本 |

**例外**：
- 银行/保险：不适用经营现金流指标，改看拨备覆盖率≥150%、不良率≤2%
- 周期股：ROE 看周期中枢而非当前值

### 1.2 加分项（满足越多越好）

来源：巴菲特十二准则 + 段永平商业模式评估

| 指标 | 优秀 | 合格 | 说明 |
|------|------|------|------|
| 毛利率 | ≥ 60% | ≥ 40% | 定价权与护城河的量化体现 |
| 净利率 | ≥ 25% | ≥ 15% | 商业模式质量 |
| 有息负债率 | ≤ 20% | ≤ 50% | 财务安全（非金融企业） |
| 营收3年CAGR | ≥ 15% | ≥ 8% | 成长性（成熟企业可放宽） |
| 自由现金流/净利润 | ≥ 70% | ≥ 50% | 真实盈利能力 |
| 股息率 | ≥ 3% | ≥ 1% | 股东回报意愿 |

### 1.3 排除项（触碰即排除）

来源：段永平不为清单 + 老唐财报排雷

| 排除条件 | 识别方法 |
|---------|---------|
| 生意看不懂 | 主营业务超过3个不相关领域；复杂金融衍生品为主业 |
| 利润依赖补贴 | 补贴/营业外收入占利润>30% |
| 频繁变更会计政策 | 近3年变更会计政策≥2次且无合理理由 |
| 大额商誉 | 商誉/净资产 > 30% |
| 存贷双高 | 货币资金充裕但有息负债高（利息支出/有息负债 < 2%） |
| 应收异常 | 应收账款增速 > 营收增速 × 1.5 |

## 二、高股息条件集

适用于：追求稳定现金回报、偏保守的投资者。

### 2.1 硬门槛

| 指标 | 阈值 | 说明 |
|------|------|------|
| 股息率 | ≥ 3%（近3年均值） | 真正的现金回报 |
| 派息比率 | ≥ 50%（近3年均值） | 分红意愿与能力 |
| 经营现金流/净利润 | ≥ 90% | 分红的资金来源必须真实 |
| 有息负债率 | ≤ 40% | 财务安全，确保分红可持续 |
| ROE | ≥ 10% | 资本效率底线 |

### 2.2 加分项

| 指标 | 优秀 | 合格 |
|------|------|------|
| 连续分红年数 | ≥ 10年 | ≥ 5年 |
| 股息增长率(3年CAGR) | ≥ 8% | ≥ 3% |
| 派息比率稳定性 | 波动<10% | 波动<20% |

### 2.3 排除项

| 排除条件 | 说明 |
|---------|------|
| 分红靠借款 | 经营现金流不足以覆盖分红+资本支出 |
| 周期顶部分红 | 处于行业景气顶点的高股息不可持续 |
| 分红率突变 | 突然大幅提高分红可能是大股东套现 |

## 三、周期反转条件集

适用于：在行业低谷期寻找可能反转的标的。

### 3.1 硬门槛（不同于标准集）

| 指标 | 阈值 | 说明 |
|------|------|------|
| 市净率(PB) | ≤ 1.5 | 低估值的保护 |
| 行业地位 | 前三名 | 只有龙头才能穿越周期 |
| 资产负债率 | ≤ 60% | 周期低谷的生存能力 |
| 经营现金流 | 最近一年为正 | 还没到现金流断裂 |

### 3.2 周期特殊性调整

- **ROE 不适用当期值**：周期低谷 ROE 可能<5%，需看上一个完整周期的中枢 ROE（≥12%）
- **利润增速不适用**：周期股利润波动大，改看营收的周期稳定性
- **关键指标**：产能利用率拐点、产品价格拐点、库存拐点——这些是反转信号

### 3.3 排除项

| 排除条件 | 说明 |
|---------|------|
| 上轮周期也未盈利 | 不是周期问题，是生意本身差 |
| 负债率>70% | 周期低谷可能撑不过去 |
| 核心资产贬值快 | 技术迭代导致产能淘汰 |

## 四、港股特殊考量

筛选港股时，在标准条件基础上额外关注：

| 维度 | 港股特殊点 | 筛选条件 |
|------|-----------|---------|
| 流动性 | 港股小票流动性极差 | 日均成交额 ≥ 500万港元 |
| 做空 | 港股可做空，被做空需警惕 | 近1年有无做空报告 |
| 老千股 | 港股存在合股/供股/削股套路 | 排除频繁合股供股的公司 |
| 信息披露 | 港股年报为英文/繁体 | 确认能获取年报信息 |
| 汇率 | 人民币贬值风险 | 评估港币/人民币汇率影响 |
| 南向资金 | 内地资金偏好 | 关注港股通标的 |

## 五、A股特殊考量

| 维度 | A股特殊点 | 筛选条件 |
|------|-----------|---------|
| 退市风险 | 注册制退市趋严 | 排除ST/*ST/退市风险警示 |
| 限售股解禁 | 大量解禁冲击股价 | 关注近期限售股解禁比例 |
| 行业政策 | 政策驱动明显 | 排除政策明确不支持的行业 |
| 机构持仓 | 北向/公募偏好 | 机构持仓占比可作为参考 |

## 条件使用原则

1. **条件是过滤器不是选择器**：通过条件只说明"可以看"，不代表"应该买"
2. **宁可漏掉好公司不可放进差公司**：条件应偏严格，漏掉的可以后补，放进差的浪费时间
3. **数据口径一致**：比较时必须用相同口径（TTM vs 年度、合并 vs 母公司）
4. **标注数据来源**：每个数据点必须标注来自哪里（Wind/同花顺/年报/搜索结果）
5. **行业比较优于绝对阈值**：ROE 15%在白酒是低水平，在银行是高水平——条件需结合行业调整
