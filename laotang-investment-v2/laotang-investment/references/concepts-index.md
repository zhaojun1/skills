# 老唐投资体系核心概念索引

本文件汇总老唐投资体系的核心概念和关键词，用于指导知识库检索。

## 一、三大前提

| 关键词 | 含义 |
|--------|------|
| 利润为真 | 企业报告利润真实可信，非纸面利润 |
| 利润可持续 | 企业能在未来持续创造同等或更多利润 |
| 维持盈利无需大量资本投入 | 轻资产模式，自由现金流充裕 |

## 二、估值相关

| 关键词 | 含义 |
|--------|------|
| 老唐估值法 | 三年预期自由现金流 / 无风险收益率 |
| 自由现金流 | 经营现金流 - 资本开支 |
| 安全边际 | 买点 = 合理估值 × 50% |
| 无风险收益率 | 通常取 3%-4% |
| 理想买点 | 合理估值打五折 |
| 一年内卖点 | min(合理估值×150%, 当年FCF×50) |
| 戈登增长模型 | DCF 的一种变形，老唐估值法的理论基础 |

## 三、投资理念

| 关键词 | 含义 |
|--------|------|
| 能力圈 | 只投资自己能理解的企业 |
| 市场先生 | 市场是服务者而非指导者 |
| 安全边际 | 买入价格远低于内在价值 |
| 长期持有 | 找到优质企业后耐心持有 |
| 正确重注 | 凯利公式精髓：有优势时下重注 |
| 价值陷阱 | 看似便宜实则持续恶化的投资标的 |

## 四、护城河

| 关键词 | 含义 |
|--------|------|
| 无形资产 | 品牌、专利、牌照 |
| 转换成本 | 客户更换供应商的代价 |
| 网络效应 | 用户越多价值越大 |
| 成本优势 | 规模经济、独特资源 |
| 定价权 | 能将成本转嫁给客户 |
