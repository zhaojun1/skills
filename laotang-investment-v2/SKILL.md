### 步骤 1：三大前提检验

老唐投资体系的基石。任何企业必须同时满足以下三大前提，缺一不可。

逐条检验并给出明确结论：

1. **利润为真** — 企业报告的利润真实可信，非纸面利润
   - 经营现金流净额 ≥ 净利润（长期均值）
   - 应收账款/营收比率稳定，无异常跳升
   - 利润不依赖非经常性损益
   - 审计意见为无保留

2. **利润可持续** — 企业未来能持续赚取同等或更多利润
   - 行业未处于长期衰退
   - 竞争格局未明显恶化
   - 核心产品/服务未被替代
   - 政策风险不足以颠覆商业模式

3. **维持盈利无需大量新增资本投入** — 轻资产模式，自由现金流充裕
   - 资本开支/净利润 < 50%
   - 折旧摊销能覆盖维持性资本支出
   - 非重资产行业（警惕"价值陷阱"）

**判定规则**：三条中任一条不满足 → 输出"不符合三大前提，不建议纳入投资范围"，终止分析。

🔴 **CHECKPOINT**：三大前提任一不通过 → 🛑 **STOP**，不进入后续步骤。

### 步骤 2：年报财报排雷

老唐核心原则：**财报是用来排除企业的**。通过系统阅读三张表、附注和管理层披露，识别财务异常、排除问题公司。

> 完整检查清单和交叉验证方法见 `references/financial-statement-guide.md`。以下为快速参考表，详细排查必须查阅 references。

#### 2.1 资产负债表 — 快速排雷表

始终使用**合并报表**数据。母公司报表无观察价值。

| 科目 | 红灯信号 | 验证方法 |
|------|---------|---------|
| 货币资金 | 余额 ≪ 短期负债；充裕却大量借高息负债；其他货币资金巨大无解释 | 利息收入÷货币资金均值 ≈ 1.5%-3%；查附注受限vs不受限 |
| 应收账款 | 增幅远超收入增幅；1年以上占比>30%；竞争激烈却几无应收 | 查账龄、坏账计提比例、前五名欠款方；与同行对比 |
| 存货 | 增速远超营业成本增速；毛利率↑+存货↑；应计提跌价却不计提 | 查跌价准备、计价方式；农林渔牧行业直接加大怀疑 |
| 在建工程 | 数目巨大但迟迟不转固 | 查附注明细和进度 |
| 商誉 | 突然大幅增加；频繁减值；减值测试参数不透明 | 查收购作价、减值测试披露 |
| 长期待摊费用 | 金额大 | 越大资产质量越差 |
| 其他应收款 | 金额大 | 可能资金被占用 |

#### 2.2 利润表 — 快速排雷表

| 检查项 | 红灯信号 |
|--------|---------|
| 营业利润占比 | 营业外收支占比高 → 经营不稳定 |
| 毛利率变动 | 异常提升+存货大增 → 可能虚增（扩大生产摊薄固定成本） |
| 减值损失 | 大额计提后随意转回 → 操纵利润 |
| 非经常性损益 | 占净利润比例高 → 利润可持续性差 |

造假高危行业（农林渔牧 / 软件 / 集成电路 / 生物科技）：对任何异常均视为重大疑点。

#### 2.3 现金流量表 — 快速排雷表

| 检查项 | 正常标准 | 红灯信号 |
|--------|---------|---------|
| 经营现金流净额 vs 净利润 | 长期 ≥ 净利润 | 长期 < 净利润 |
| 经营现金流净额 | 为正（银行除外） | 为负 |
| 销售收现 vs 营收 | ≥ 营收 × 1.17 | 远低于营收 |

#### 2.4 附注必查科目

对报表任何项目有疑问先查附注。必查：货币资金明细（受限比例）、应收账款（账龄/坏账计提）、存货（构成/跌价）、固定资产/无形资产（折旧摊销方法是否变更）、在建工程（明细/是否长期不转固）、商誉（减值参数是否详细）、递延所得税（负债=利好 vs 资产=利空）、研发支出（资本化比例）、租赁（使用权资产/负债计量）、员工薪酬（"应付职工薪酬本期增加"÷员工总数 → 与同行历史对比）。

#### 2.5 管理层披露交叉验证

董事会报告是除三表和附注外最重要的内容，必须多年连读。

| 验证维度 | 方法 |
|---------|------|
| 历年经营计划兑现率 | 对比往年董事会报告与实际数据，兑现率<50% → 管理层可信度存疑 |
| 行业描述 vs 同行数据 | 管理层对市场的判断力 |
| 员工平均薪酬 | 附注"应付职工薪酬本期增加"÷员工总数，与同行历史对比 |
| 前十大股东变化 | 聪明资金的进退 |
| 关联交易与重要事项 | 风险排查核心章节 |

**五组必须验证的勾稽关系**：
1. 净利润 ↔ 经营现金流（长期偏离=利润质量差）
2. 营收 ↔ 应收+预收+销售收现
3. 净利润+未分配利润变化 ↔ 归母净资产变化
4. 货币资金 ↔ 现金及现金等价物（差异=受限资金，需附注解释）
5. 管理层产能/销量表述 ↔ 固定资产/在建工程+营收+附注产销数据

#### 2.6 本年度收益与风险信号

| 类型 | 信号 | 可信度 |
|------|------|:---:|
| 收益 | 预收/合同负债大幅增加 | 高 |
| 收益 | 经营现金流持续 > 净利润 | 高 |
| 收益 | 行业低谷仍保持盈利+正现金流 | 高 |
| 收益 | 固定资产账面值低但实际价值高（酒窖/大坝/核心地产） | 中 |
| 风险 | 应收增速 ≫ 营收增速 | 高 |
| 风险 | 存货增速 ≫ 销售增速 | 高 |
| 风险 | 在建工程长期不转固 | 高 |
| 风险 | 频繁变更会计政策（≥3次/3年） | 高 |
| 风险 | 关联交易占比高 | 高 |
| 风险 | 其他应收款金额大 / 长期待摊费用异常偏高 | 中高 |

**判定规则**：任一重大异常无法合理解释 → 输出"财报存在重大疑点，建议排除"，终止分析。

🔴 **CHECKPOINT**：财报发现重大异常且无法合理解释 → 🛑 **STOP**，输出排除结论。

### 步骤 3：老唐估值法

> 仅对通过步骤 1（三大前提）和步骤 2（财报排雷）的企业执行。

🔴 **CHECKPOINT**：确认步骤 1 ✅ + 步骤 2 ✅ 后再执行，任一未通过 → 不进入估值。

1. **确定基期正常化自由现金流**：取最近 3-5 年自由现金流（经营现金流 - 资本开支）的均值，剔除异常年份
2. **预估未来三年增长率**：上限 15%/年。超过此值须列出至少 3 条量化依据（行业增速 + 市场份额 + 新业务贡献）
3. **计算三年后预期自由现金流**：基期值 × (1 + 增长率)^3
4. **确定合理估值**：三年后预期自由现金流 ÷ 无风险收益率（取 3%-4%，对应 25-30 倍市盈率）
5. **计算理想买点**：合理估值 × 50%（五折安全边际）
6. **计算一年内卖点**：min(合理估值 × 150%, 当年预期 FCF × 50)

🔴 **CHECKPOINT**：增长率 > 15% → 列出至少 3 条量化依据，否则强制降至 15%，标注「保守假设」。

**特殊处理**：
- 周期性企业：使用周期中枢盈利，不用峰值
- 金融企业（银行/保险）：不适用自由现金流估值，改用 PB/ROE 框架
- 亏损/微利企业：不适用老唐估值法，等待盈利稳定后再评估
- 自由现金流波动剧烈（标准差 > 均值）：取最低年份值作为保守基期，标注「采用保守基期」

### 步骤 4：护城河与竞争分析

基于知识库中的护城河分析框架：

1. **护城河类型识别**（可同时具备多种）：
   - 无形资产（品牌溢价、专利、牌照、法定许可）
   - 转换成本（客户更换的代价）
   - 网络效应（用户越多价值越大）
   - 成本优势（规模经济、独特资源、地理位置）

2. **护城河宽度**：宽（难以逾越）/ 窄（可被侵蚀）/ 无

3. **护城河趋势**：加宽 / 稳定 / 变窄

### 步骤 5：风险识别

列出至少覆盖以下维度的风险清单。每个风险给出：描述 → 可能性（高/中/低）→ 影响程度（高/中/低）。

| 维度 | 重点关注 |
|------|---------|
| 财务风险 | 步骤 2 中发现的异常信号 |
| 商业模式风险 | 核心逻辑是否可能被颠覆 |
| 竞争风险 | 竞争对手的威胁程度 |
| 管理层风险 | 治理结构、诚信与能力（含步骤 2.5 兑现率评估） |
| 估值风险 | 当前估值是否透支未来 |
| 宏观/政策风险 | 行业监管、经济周期影响 |

### 步骤 6：生成投资备忘录

将分析整合为结构化备忘录。

🔴 **CHECKPOINT**：生成前确认五步均已完成且无未处理异常 — 三大前提 ✅ / 财报排雷 ✅ / 估值 ✅ / 护城河 ✅ / 风险 ✅。

## 失败模式与处理路径

分析过程中遇到异常场景时按以下三段式路径处理，不静默跳过。

### 知识库与数据获取

| 触发条件 | 一线修复 | 仍失败兜底 |
|----------|---------|-----------|
| 知识库检索无结果 | 扩大搜索词范围（同义词、简称/全称），重试 | 基于 references 文件和通用框架继续，在"知识库依据"标注「本次未检索到知识库内容」 |
| 单项财务指标数据缺失 | 用其余正常年份均值/中位数补全，标注「某年数据缺失」 | 跳过该指标，注明「因数据缺失未评估」，不因单项缺失终止 |
| references 文件不可读 | 使用本 SKILL.md 内嵌的排雷清单和估值步骤 | — |

### 用户输入边界

| 触发条件 | 一线修复 | 仍失败兜底 |
|----------|---------|-----------|
| 用户未指定具体企业/股票 | 列出需要的信息（公司名称 + 分析深度），要求补充 | 等待用户回复，不执行分析 |
| 用户要求分析金融企业 | 输出「老唐估值法不适用金融企业，改用 PB/ROE 框架」，询问是否继续 | 用户坚持 → 标注「非老唐标准框架」后执行 |

### 财报数据异常

| 触发条件 | 一线修复 | 仍失败兜底 |
|----------|---------|-----------|
| 三表勾稽关系矛盾 | 标注具体矛盾项及差异金额，在备忘录标记 🔴 高风险 | 矛盾无法合理解释 → 判定「建议排除」 |
| 企业处于造假高危行业 | 加大怀疑力度，逐项严格审查 | 任何异常均视为重大疑点 |
| 会计政策频繁变更（≥3 次/3 年） | 逐项列出变更及对利润的影响金额，计算还原后可比利润 | 变更理由不合理 → 判定「建议排除」 |
| 管理层经营计划兑现率 < 50% | 管理层可信度评级降为「低」，风险清单单独列「管理层诚信风险-高」 | — |
| 审计意见非标准无保留 | 备忘录首段标注「⚠️ 审计意见异常」 | 无法判断影响 → 判定「建议排除」 |

### 估值假设边界

| 触发条件 | 一线修复 | 仍失败兜底 |

| 自由现金流波动剧烈（标准差 > 均值） | 取最低年份值作为保守基期，标注「采用保守基期」 | — |
