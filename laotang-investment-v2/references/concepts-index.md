# 老唐投资体系核心概念索引

本文件汇总老唐投资体系的核心概念和关键词，用于指导知识库检索。

## 一、三大前提

| 关键词 | 含义 |
|--------|------|
| 利润为真 | 企业报告利润真实可信，非纸面利润 |
| 利润可持续 | 企业能在未来持续创造同等或更多利润 |
| 维持盈利无需大量资本投入 | 轻资产模式，自由现金流充裕 |

## 二、估值相关

| 关键词 | 含义 |
|--------|------|
| 老唐估值法 | 三年预期自由现金流 / 无风险收益率 |
| 自由现金流 | 经营现金流 - 资本开支 |
| 安全边际 | 买点 = 合理估值 × 50% |
| 无风险收益率 | 通常取 3%-4% |
| 理想买点 | 合理估值打五折 |
| 一年内卖点 | min(合理估值×150%, 当年FCF×50) |
| 戈登增长模型 | DCF 的一种变形，老唐估值法的理论基础 |

## 三、投资理念

| 关键词 | 含义 |
|--------|------|
| 能力圈 | 只投资自己能理解的企业 |
| 市场先生 | 市场是服务者而非指导者 |
| 安全边际 | 买入价格远低于内在价值 |
| 长期持有 | 找到优质企业后耐心持有 |
| 正确重注 | 凯利公式精髓：有优势时下重注 |
| 价值陷阱 | 看似便宜实则持续恶化的投资标的 |
| 财报是用来排除企业的 | 老唐读财报的核心理念，先排雷再研究 |

## 四、护城河

| 关键词 | 含义 |
|--------|------|
| 无形资产 | 品牌、专利、牌照 |
| 转换成本 | 客户更换供应商的代价 |
| 网络效应 | 用户越多价值越大 |
| 成本优势 | 规模经济、独特资源 |
| 定价权 | 能将成本转嫁给客户 |

## 五、财报排雷关键词

| 关键词 | 关联排雷方向 |
|--------|-------------|
| 货币资金 | 短期偿债、资金虚构、大股东占用 |
| 应收账款 | 虚增收入、坏账风险、信用政策激进 |
| 存货 | 滞销、虚增利润、跌价风险 |
| 在建工程 | 资金挪用、避免折旧、造假 |
| 商誉 | 收购作价不公、减值调节利润 |
| 减值/减值转回 | 洗大澡、毁尸灭迹、操纵利润 |
| 关联交易 | 循环交易虚增收入、利益输送 |
| 其他应收款 | 资金占用、私设小金库 |
| 长期待摊费用 | 费用资本化、资产质量差 |
| 会计政策变更 | 调节利润 |
| 预收/合同负债 | 未来收入确定性 |
| 经营现金流 | 利润质量、赊销虚增收入 |
| 附注 | 三张表的解释说明，必须审查 |
| 董事会报告 | 管理层可信度、承诺兑现率 |
| 递延所得税 | 负债=无息贷款（利好），资产=提前纳税（利空） |
| 研发支出资本化 | 美化资产和利润 |

## 六、造假高危行业

| 行业 | 风险原因 |
|------|----------|
| 农林渔牧 | 生物资产数量和价值难核实 |
| 软件 | 收入确认灵活、研发资本化空间大 |
| 集成电路 | 产品差异化小、审计验证难度高 |
| 生物科技 | 研发支出大、政策补贴多 |

## 八、新准则关注点

| 准则 | 施行时间 | 对分析的影响 |
|------|----------|-------------|
| 新金融工具准则 | 境内外上市2018年/境内2019年 | 金融资产分类变更、减值计提规则变化 |
| 新收入准则 | 境内外上市2018年/境内2020年 | 收入确认时点和计量方式变化，关注是否提前确认收入 |
| 新租赁准则 | 境内外上市2019年/境内2021年 | 使用权资产+租赁负债入表，资产负债率上升，前期利润偏高 |
